# Third-party dataset notice

This repository does not redistribute dataset files. The experiments use
preprocessed versions of the following public network datasets distributed by
the Stanford Network Analysis Project (SNAP):

- [Bitcoin Alpha](https://snap.stanford.edu/data/soc-sign-bitcoin-alpha.html)
- [Bitcoin OTC](https://snap.stanford.edu/data/soc-sign-bitcoin-otc.html)
- [Epinions](https://snap.stanford.edu/data/soc-sign-epinions.html)
- [Slashdot Zoo](https://snap.stanford.edu/data/soc-sign-Slashdot090221.html)
- [Wikipedia Requests for Adminship](https://snap.stanford.edu/data/wiki-RfA.html)

Download the datasets from their original pages and prepare three-column signed
edge lists as described in the README. The repository's MIT License applies only
to the software and documentation authored for PASC; it does not relicense these
third-party datasets. Users are responsible for complying with the terms and
citation requirements of the original dataset distributors.
